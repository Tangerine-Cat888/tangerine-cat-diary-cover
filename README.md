# 日记封面 Skill

根据指定月份的日记建议书名，寻找有来源的艺术作品或摄影图片，并制作封面对比。

## 功能

- 只读取指定的日记范围，整理主题并提出书名候选。
- 根据标题、封面模板及实际书架尺寸筛选图片。
- 核对作品作者、出处与许可；涉及获奖摄影时核对奖项来源。
- 提供候选对比，说明匹配理由、裁切和不足。
- 适配朝花夕拾 / Obsidian；在用户授权范围内应用并验证封面。

## 安装

下载本仓库的 ZIP，解压后将文件夹改名为 `tangerine-cat-diary-cover`，放进 Agent 的技能目录。文件夹内应直接包含 `SKILL.md`。

Codex 用户可放入 `$CODEX_HOME/skills`，未设置时使用 `~/.codex/skills`。在新会话里调用 `$tangerine-cat-diary-cover`；也可以向 Agent 提供 SKILL.md 的路径。

## 使用示例

> 用日记封面 Skill，读取我指定目录中这个月的日记，先建议书名，再找配图做封面对比。这次只预览，不修改日记本。

请告知日记目录和月份。Agent 需要读取文件、检索网页及处理图片的能力；实际插件预览与应用还需要相应的软件访问能力。仅选择模板不会写入未选定的图片；明确只预览时不会应用。

## 隐私与图片来源

本仓库不包含日记、用户配置、账号凭据或画作图片。外部检索使用通用主题词及公开作品信息，不发送日记原文。Agent 服务本身如何处理提供的日记，取决于你使用的服务和设置。

图片的使用权按单件作品核验。本仓库的 MIT 许可证仅覆盖仓库中的 Skill 文本及配置，不授予第三方艺术作品或摄影图片的使用权。
